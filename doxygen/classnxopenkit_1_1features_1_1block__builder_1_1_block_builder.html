Detailed Description

Configure and create NX block features.

Supports origin-and-length, two-points-and-height, and diagonal-points
construction modes. Boolean operations and origin associativity can be
configured before committing the feature.

Initialize a block feature builder.

Args:
    type (NXOpen.Features.BlockFeatureBuilder.Types): Block creation mode.
    origin_point (Point): Origin or first diagonal point.
    second_point (Point, optional): Second point for applicable modes.
    xc_length (Double, optional): X edge length. Defaults to 100.
    yc_length (Double, optional): Y edge length. Defaults to 100.
    zc_length (Double, optional): Z edge length or height. Defaults to 100.

Returns:
    None: The builder is initialized.

Raises:
    TypeError: If a required point has the wrong type.
    ValueError: If a required numeric value is invalid.
