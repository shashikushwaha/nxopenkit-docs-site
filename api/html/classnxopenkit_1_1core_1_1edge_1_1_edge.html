static 
Retrieve all edges tangential to the seed_edge (and end_edge if
specified) within the specified angle tolerance.

Args:
    seed_edge (Edge): The edge from which to find tangent edges.
    end_edge (Optional[Edge], optional): The edge at which to stop the
    tangent edge search. Defaults to None.
    is_from_seed_start (bool, optional): If True, the search for tangent
    edges will start from the seed_edge's start point. Defaults to False.
    angle_tolerance (float, optional): The angle tolerance within which
    edges are considered tangent. Defaults to 0.5.
    destroy_section (bool, optional): If True, the section of the curve
    between the seed_edge and the found tangent edges will be deleted.
    Defaults to True.

Returns:
    List[Edge]: A list of edges tangential to the seed_edge (and end_edge
    if specified).
