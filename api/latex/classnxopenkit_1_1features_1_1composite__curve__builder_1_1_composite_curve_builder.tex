\doxysubsection{Detailed Description}
\begin{DoxyVerb}Create and configure a composite curve feature.

A composite curve combines curves or edges selected by selection-intent rules
into a single NX feature. Builder operations support associativity, original
object display, self-intersection handling, and advanced curve fitting.
\end{DoxyVerb}
